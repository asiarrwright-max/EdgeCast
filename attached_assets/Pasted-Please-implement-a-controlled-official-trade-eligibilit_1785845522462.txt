eligibility_reason = "same_day_not_approved"

3. HARD CUTOFF AND TIMEZONE GUARD
Before creating any trade, confirm:
- current time is before the actual Kalshi market close/settlement cutoff;
- settlement date and cutoff are interpreted in the settlement location’s timezone;
- the outcome has not already been observed;
- apply a configurable safety buffer before cutoff.

official_trade_cutoff_buffer_minutes = 120

If the exact cutoff cannot be verified, do not create an official trade.

Reason:
"cutoff_unverified_or_too_close"

Add regression tests covering the prior UTC/local-date error that allowed trades after target_settlement_date.

4. ENTRY-PRICE FLOOR
Official paper trades require executable entry price >= $0.20.

Contracts below $0.20 remain visible as research-only:
eligibility_reason = "entry_price_below_official_floor"

This applies to both YES and NO entry prices.

Make the threshold configurable:
official_min_entry_price = 0.20

5. EXTREME-EDGE GUARD
If claimed edge >= 50 percentage points, classify the signal as research-only instead of an official paper trade.

Reason:
"extreme_edge_requires_validation"

Make configurable:

Do not cap or alter the stored probability. Preserve the original probability and edge for analysis.

eligibility_reason = "correlated_outcome_limit"
